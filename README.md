# Ebookeria

## 📚 Descrição

Ebookeria é uma plataforma para gerenciar e compartilhar eBooks. O sistema permite que usuários explorem uma coleção de livros digitais, visualizem detalhes sobre cada ebook e façam sua compra em links externos.  

## 🚀 Funcionalidades

- Listagem de eBooks disponíveis  
- Página de detalhes para cada eBook (título, autor, descrição, data, etc.)  
- Upload de novos eBooks
- Interface responsiva para visualização em dispositivos móveis e desktops  

## 🛠️ Tecnologias

- Backend: PHP.  
- Frontend: HTML5, CSS3, JavaScript. 
- Banco de dados: MySQL.
