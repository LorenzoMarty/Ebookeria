# Ebookeria

Ebookeria é uma plataforma para gerenciar e compartilhar eBooks. 
O sistema permite que usuários explorem uma coleção de livros digitais, visualizem detalhes sobre cada ebook e façam sua compra em links externos.

## Funcionalidades

- Listagem de eBooks disponíveis  
- Página de detalhes para cada eBook (título, autor, descrição, data, etc.)  
- Upload de novos eBooks
- Interface responsiva para visualização em dispositivos móveis e desktops  

## Diferencial

O sistema foi pensado para:
- Usuários consigam acessar facilmente os livros digitais de seu interesse
- Uso fácil

## Arquitetura

Fluxo principal:

1. O admin loga
2. O admin cadastra um ebook, com seus dados e link de compra
3. O usuário navega pelo catálogo e escolhe um ebook
4. O usuário é redirecionado para página de compra do ebook
